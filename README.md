# Duration-Guided KG Retrieval — pipeline

Retrieval and evaluation code for *基於病程時間引導的知識圖譜檢索於醫療問答*.

The pipeline is deliberately split in two, and the split is the thing to understand first:

```
   ┌── Stage A: RETRIEVAL (slow, costs Neo4j + LLM) ────────────────────────┐
   │  benchmark.json ──> seeds/symptoms/durations ──> KG walk / baselines   │
   │                                          ──> frozen/<ds>/<method>.json │
   └────────────────────────────────────────────────────────────────────────┘
                                     │   {uid, gold, route, kg_block, prompt}
                                     │   kg_block stored SEPARATELY from prompt
   ┌── Stage B: READING (fast, costs one LLM call per question) ───────────┐
   │  frozen file ──> run_reader.py ──> results/<dir>/<ds>_<method>.json    │
   └────────────────────────────────────────────────────────────────────────┘
```

Because `kg_block` is frozen apart from `prompt`, a prompt can be rewritten without touching
Neo4j: `rerender_prompts.py` rebuilds the wording from byte-identical evidence. That is what makes
a prompt A/B a controlled comparison rather than a re-run.

## Setup

```bash
pip install neo4j openai tqdm scipy          # scipy only for the paired tests in the reports
export NEO4J_URI=bolt://localhost:7687
export NEO4J_USER=... NEO4J_PASSWORD=...
export OPENAI_API_KEY=...                    # or LITELLM_API_KEY / TOGETHER_API_KEY
```

No credential is stored in tracked source. Loaders in `code/llm_client.py` read environment
variables first, then files under `api_key/` (gitignored). A missing key returns an empty token and
the call fails loudly rather than silently using someone else's quota.

`cache/`, `frozen/`, `results/`, `logs/` and `datasets/*/` are gitignored — ~1.9 GB of regenerable
output. Only `datasets/*/temporal_critical.json` is kept, because those labels are hand-made and
cannot be regenerated by running anything.

`cui_to_tui.csv` (CUI → semantic type, 443,700 rows) is also gitignored: it is UMLS-derived, and
the UMLS licence restricts redistribution. Rebuild it from your own licensed instance:

```cypher
MATCH (c:Concept) RETURN c.cui AS CUI, c.tui AS TUI_list
```

## Running

```bash
python3 prepare_dataset_inputs.py            # seeds / symptoms / durations for a new dataset
bash run_stage_a.sh <dataset>                # every retrieval method, sequentially
bash rerender_all_kg.sh <dataset> revised prompt_revised.txt
DATASET=<ds> METHOD=walker N_RUNS=3 RESULTS_DIR=results/revised_prompt python3 run_reader.py
python3 metrics_report.py <dataset>
```

Stage A is sequential on purpose: each walker worker holds ~4 GB of SapBERT matrix, and two
retrieval jobs at once has previously exhausted a 38 GB machine.

## Files

### Stage A — retrieval
| file | role |
|---|---|
| `prepare_dataset_inputs.py` | seeds / symptoms / query entities / durations for a new dataset |
| `build_kg.py` | the walker: `score = cos + λ·bc − μ·hop`, `WALKER_BC_MODE=overlap\|interval_sample` |
| `build_raw_hops.py` | unfiltered 1-hop / 2-hop neighbour dumps (control) |
| `code/tog_baseline.py` | Think-on-Graph baseline |
| `code/hykge_baseline.py` | HyKGE baseline |
| `build_prompt_only.py` | no-KG prompts (vanilla / cot) |
| `freeze_baseline.py` | baseline cache → the shared frozen schema |
| `run_stage_a.sh` | runs all of the above for one dataset |

### Stage B — reading and scoring
| file | role |
|---|---|
| `run_reader.py` | replays frozen prompts N times; writes accuracy + `metrics` |
| `answer_extract.py` | pulls the option letter out of raw output |
| `metrics.py` | accuracy, macro/weighted precision·recall·F1, parse failures |
| `prompts.py` | prompt surgery shared by the readers |
| `rerender_prompts.py` | rebuild a prompt from frozen evidence (no retrieval) |

### Reports
| file | role |
|---|---|
| `metrics_report.py` | accuracy + precision/recall/F1 per dataset and prompt variant |
| `prompt_ab_report.py` | old vs revised prompt, same evidence, with paired tests |
| `results_by_temporal_subset.py` | all questions vs the temporal-critical subset |
| `final_report.py` | consolidated view, with vanilla as the yardstick for subset difficulty |
| `dataset_statistics.py` | ReinRAG-style corpus statistics |

### Dataset construction and verification
| file | role |
|---|---|
| `build_new_dataset.py` | assemble MedBullets / MMLU-Med / MedMCQA benchmarks |
| `verify_duration_critical.py` | counterfactual perturbation test |
| `verify_openended_probe.py` | open-ended probe (the second arm) |
| `dump_for_manual_read.py` | compact dump for per-question hand review |
| `label_temporal_critical.py` | writes hand-review labels into the dataset |

`verification/manual_read_*.jsonl` holds 723 per-question hand verdicts. Those are the ground truth
for every temporal-critical split; nothing regenerates them.

## Known caveat

`metrics.py` scores ANSWER LETTERS. Macro precision/recall over letters measures the reader's
position bias, not diagnostic quality, and it is a different quantity from the retrieval recall the
method is argued on (does the gold concept reach the retrieved pool). Do not put both under one
"recall" heading. On 329 two letters have a single gold question each, so read `weighted_*` there,
not `macro_*`.

`new_metrics.py` is the original sketch these definitions came from. It does not parse and is
superseded by `metrics.py`.
